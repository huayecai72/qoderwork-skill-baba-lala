# 叭叭啦啦 v2

> 快速响应的行业短评小喇叭——深度文章还在打磨？先让叭叭啦啦出个声占个位。

## 适用场景
- 电商大促（618/双11/年货节等）后的行业分析
- 消费品牌/赛道趋势短评
- 平台数据解读、平台政策变化
- 商业新闻快速点评（品牌融资、行业事件）

## 输出规格
- **字数**：550-650字
- **标题**：3-5个备选，标注手法类型
- **平台**：微信贴图或小红书
- **风格**：资深分析师/行业大V，有观点有温度，可直接发布

## 工作流程

### Step 0：判定锁定等级

根据用户prompt的明确程度，确定本次写作的确定性等级：

| 等级 | 触发条件 | 锁定范围 |
|------|---------|---------|
| **L3 全锁** | 用户给了数据+明确定调方向（含"核心逻辑是""论点是""主论点""定调"等指令词） | 结构+论点+口吻+论证手法全锁，AI仅负责遣词造句 |
| **L2 半锁** | 用户给了素材（链接/文本/截图）但没给定调 | 结构+口吻由规则定，论点从素材提取，切入角度允许2-3种 |
| **L1 轻锁** | 用户只给主题（如"写一篇关于XX的观察"） | 仅结构模板锁定，口吻/论点/手法开放 |

**判定规则（不可覆盖）：**
- 用户输入含"核心逻辑/定调/论点是/主论点/角度是" → L3
- 用户输入含具体素材（链接/文本/截图）但无定调指令 → L2
- 其他 → L1

### Step 1：素材预处理

**有素材时（L3/L2）：**
1. 如果是链接 → 用浏览器MCP读取全文
2. 如果是文本/截图 → 直接使用
3. 运行预处理脚本提取分析卡：
   ```bash
   python3 ~/.qoderwork/skills/baba-lala/analyze.py --input <file>
   ```
   或对短文本直接用 `--text "..."` 参数
4. 脚本输出JSON分析卡（零token消耗，纯代码执行）

**无素材时（L1）：**
- 跳过脚本，AI根据主题自行构建分析卡（格式相同，但字段允许更灵活）

**分析卡字段说明：**

| 字段 | 含义 | 绑定位置 |
|------|------|---------|
| data_points[0] | 冲击力最大的数据 | → 开头必须使用（L3/L2） |
| brands_mentioned[0] | 最完整的品牌案例 | → 正文证据块必须使用（L3/L2） |
| time_contrast | 时间对比轴 | → 正文必须出现（L3/L2，如有） |
| core_tension | 核心矛盾 | → 收尾必须回扣（L3/L2） |
| suggested_tone | 建议口吻 | → 直接采用（L3/L2） |
| suggested_template | 建议模板 | → 直接采用（L3/L2） |

### Step 2：确认分析卡

- **L3**：跳过确认（用户已给定调），将用户的定调写入core_tension
- **L2**：输出分析卡摘要给用户，用户可覆盖任何字段（如"口吻换成犀利评论员"）
- **L1**：AI自行填写，不需要用户确认

确认后，分析卡锁定，后续步骤不可偏离。

### Step 3：口吻+模板选择

**决策树（L3/L2时不可被AI覆盖，除非用户手动指定）：**

口吻：
1. 用户明确指定 → 用用户的
2. 分析卡有suggested_tone → 用分析卡的
3. 都没有 → 默认"行业观察者"

模板：
1. 用户明确指定 → 用用户的
2. 分析卡有suggested_template → 用分析卡的
3. 都没有 → 默认"A_数据驱动"

口吻详细定义见 [patterns.md](patterns.md#口吻指南)。

### Step 4：生成内容

#### 4.1 标题（3-5个备选）
从以下公式中选择，每个标题标注使用了哪种手法：

1. **反常识钩子**：`[违背直觉的事实]`
2. **悬念钩子**：`[场景]的[人群]，都做对了[悬念词]`
3. **数据冲击+反问**：`[冲击力数据]，[反问]？`
4. **挑衅式判断**：`[旧做法]，[否定/重定义]`
5. **比喻+转折**：`[场景]，[意外转折]`

**规则**：15-28字 | 含时间/场景锚点 | 用阿拉伯数字 | 不用"震惊"等低质词

#### 4.2 开头（2-3句，约80字）

**硬性槽位**：L3/L2时，必须包含 analysis_card.data_points[0]。

**结构选择**：
- **旧共识→转折→新发现**（最常用）
- **场景切入**：极具体的生活细节→跳到数据验证
- **数据开场**：1-2个冲击力数据→"这意味着..."

**禁忌**：不写百科式科普 | 不超过3句还没进正题

#### 4.3 正文（300-400字，2-3个证据块）

**硬性槽位**：
- L3/L2时：证据块1必须使用 analysis_card.brands_mentioned[0]
- L3/L2时：如有 time_contrast，必须出现时间对比句
- 所有等级：core_tension 必须在正文中被明确表达

每个证据块结构：**论点（1句）→ 数据/案例（1-2句）→ 解读（1句）**

**论证工具箱**（每篇选3-4种）：
- **数据背书**：引用数据，标注来源，紧跟解读
- **案例驱动**：具体品牌名+做法+结果
- **时间对比**："去年 vs 今年"
- **"不是A而是B"**：推翻旧认知（每篇2-3句）
- **比喻类比**：用日常事物解释商业概念
- **造概念/命名**：给现象取4-6字新名字

#### 4.4 收尾（1-2句，约60字）

**硬性槽位**：L3/L2时，必须回扣 analysis_card.core_tension。

- **升华式**：从具体现象跳到行业大势判断
- **呼应式**：回扣开头的故事/问题
- **落地式**：一句有力的判断或金句

**禁忌**：不用"综上所述" | 不塞新案例新数据 | 不超过全文10%

#### 4.5 金句（全文2-3句，分布在各处）
- **对立重构**："不是A，而是B"
- **比喻定格**：抽象概念→具象比喻
- **数字锤击**：冲击力数据+简短判断
- **时间压缩**："过去...→现在..."

金句前后留白，不连续出现。

### Step 5：交付格式

```
【标题备选】
1. [标题A]（反常识钩子）
2. [标题B]（数据冲击+反问）
3. [标题C]（悬念钩子）
...

【正文】
[完整短评，可直接发布]

【字数统计】约XXX字
【分析卡摘要】事件:XX | 口吻:XX | 模板:XX | 核心矛盾:XX
```

## 叙事素材包

**位置**：skill目录下的 `narrative-*.md` 文件（如 `narrative-618-2026.md`）

**加载规则（重要：不自动加载）**：
1. 优先使用用户当次给的素材（分析卡已提取）
2. 分析卡缺品牌案例或比喻时 → 从对应事件的叙事包中拉取相关段落
3. 叙事包与当次素材冲突时 → 以当次素材为准
4. 无对应事件的叙事包 → 不加载，纯靠素材和AI通用能力

**扩展**：每次大促/重大事件后，蒸馏新文章为新的叙事包文件即可，skill本体不用改。

## 平台立场指南

对淘宝/天猫保持**中立偏正面但不硬夸**：
- 数据和案例自然呈现平台正面效果，不刻意强调
- 把平台当"数据引用来源"而非"广告主体"
- 用观察者口吻提及（"值得注意的是"、"有意思的是"）
- **绝不用**："强烈推荐"、"首选平台"、"最好的选择"等推销用语
- **绝不**：整篇围绕平台夸、对竞品拉踩、像广告软文

---

## 禁忌清单

- 百科式科普开头
- 面面俱到的平衡报道（要有立场）
- 空洞行业黑话堆砌（"赋能品牌实现全域营销的品效合一"）
- 过度感叹号和情绪词（"太厉害了！"）
- 案例堆砌无分析
- 结论先行无论证
- 段落过长（>4句）
- 数据无解读
- "综上所述"等论文式收尾
- 口语化失控（口语化是"皮"，逻辑严谨是"骨"）

## 质量检查

写完后逐项核对：
- [ ] 标题有钩子且含时间/场景锚点
- [ ] 开头3句内进入核心论点
- [ ] 开头包含分析卡data_points[0]（L3/L2）
- [ ] 正文有2-3个证据块（数据+案例）
- [ ] 正文包含分析卡brands_mentioned[0]（L3/L2）
- [ ] 正文出现时间对比（L3/L2，如分析卡有time_contrast）
- [ ] 融入了用户给的核心逻辑（用自己的话）
- [ ] 有"不是A而是B"句式
- [ ] 有至少1个比喻/类比
- [ ] 2-3句金句分布各处
- [ ] 段落不超过4句
- [ ] 收尾回扣core_tension（L3/L2）
- [ ] 收尾短而有力
- [ ] 总字数550-650
- [ ] 平台提及自然不硬夸
- [ ] 不拉踩竞品
