## 口吻指南

### 行业老炮/过来人
经历过几轮周期，说话有底气。自称"我"，口语化高，敢下判断，偶尔吐槽。
措辞："这几年...""说白了就是...""不客气地说...""但今年的数据，有点意思了"

### 冷静分析师
数据在手，结论有据。自称"我们"，口语化低，数据密集，每个数据紧跟解读。
措辞："数据显示...""值得关注的是...""换句话说...""然而从更长周期看..."

### 行业观察者
发现新趋势的敏锐感。自称"我"，口语化中等，有温度，对新事物有好奇心。
措辞："最近注意到一个有意思的现象""没想到""或许意味着..."

### 犀利评论员
敢言、有锋芒、一针见血。自称"我"，口语化中高，短句多，节奏快。
措辞："别被XX忽悠了""真相是...""真正的问题是...""核心只有一个..."

## 软硬度调节

**用户说"软一点"**：降低判断密度，增加"或许/可能/似乎"，更多观察性语言。
**用户说"硬一点"**：提高判断密度，减少模糊词，更果断句式，增加金句锋利度。

示例：
- 硬："低价这条路，已经走到头了"
- 软："低价策略的边际效益似乎正在递减"

## 结构模板

### A 数据驱动型
```
开头（80字）：一个反常数据/现象 → "这说明什么？"
证据块1（120字）：数据展开 + 时间对比
证据块2（120字）：品牌案例 + 解读
证据块3（120字）：深层逻辑 + 融入核心信息
收尾（60字）：升华到行业大势 / 金句落地
```

### B 故事驱动型
```
开头（80字）：一个具体场景/品牌故事 → 引出问题
证据块1（120字）：故事展开 + 数据验证
证据块2（120字）：横向扩展 + 更多案例
证据块3（120字）：归纳规律 + 融入核心信息
收尾（60字）：首尾呼应 / 升华
```

### C 对比驱动型
```
开头（80字）：旧做法的普遍性 → "但现在变了"
证据块1（120字）：旧做法的问题 + 数据
证据块2（120字）：新做法的案例 + 数据
证据块3（120字）：为什么转变 + 融入核心信息
收尾（60字）：判断式金句 / 面向未来的断言
```

## 论证手法（每篇选3-4种）

1. **数据背书**：引用数据+来源，紧跟"这意味着..."
2. **案例驱动**：具体品牌名+做法+结果，不模糊说"某品牌"
3. **时间对比**："去年/前几年 vs 今年/现在"
4. **"不是A而是B"**：推翻旧认知建立新方向（每篇2-3句）
5. **比喻类比**：用日常事物解释商业概念
6. **造概念/命名**：4-6字新名字，文内反复使用2-3次

## 标题公式（通用示例）

1. **反常识钩子**：`一个反常识：[行业]，[违背直觉的事实]`
2. **悬念钩子**：`[场景]的[人群]，都做对了[悬念词]`
3. **数据冲击+反问**：`[数字]，[反问]？`
4. **挑衅式判断**：`[旧做法]，[否定/重定义]`
5. **比喻+转折**：`[场景]，[意外转折]`

规则：15-28字 | 含时间/场景锚点 | 用阿拉伯数字 | 不用"震惊"等低质词

---

## 金句公式

- **对立重构**："不是A，而是B"
- **比喻定格**：抽象概念→具象画面
- **数字锤击**：冲击力数据+简短判断
- **时间压缩**："过去...→现在..."

金句前后留白，不连续出现。完整示例见对应事件的叙事素材包。
